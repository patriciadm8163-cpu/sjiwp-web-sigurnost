CYBERGUARD – WEB PROJEKT

Otvorite index.html u pregledniku.

Struktura:
- HTML podstranice: index.html, o-nama.html, usluge.html, novosti.html, clanak1.html, clanak2.html, kontakt.html
- Zajednički CSS: css/stil.css
- JavaScript validacija kontakt forme: js/skripta.js
- mapa je ugrađena preko Google Maps iframea

Napomena:
Projekt namjerno koristi CSS grafičke elemente umjesto vanjskih fotografija kako bi radio odmah nakon raspakiravanja.
Newsletter polje u footeru je vizualni obrazac. Za stvarni Mailchimp embedded form potrebno je zalijepiti Mailchimpov generirani embed kod.
